# 药企NBA / NBC（Next Best Action / Next Best Conversation）通俗解析

> **可以类比电商推荐，但不是面向C端消费者，是面向B端的医生（HCP）；不是给用户推商品，是给药企销售/医学代表推「下一步该怎么做」的行动建议。**
- **NBA（Next Best Action）：最佳下一步行动**：该拜访哪位医生、用什么渠道、什么时间触达。
- **NBC（Next Best Conversation）：最佳对话内容**：和这位医生该聊什么学术话题、推送哪份临床资料、用哪些话术要点。

## 一、真实落地形式（工程侧要做的事情，对应JD岗位）
输出的**不是面向医生的聊天机器人**，是嵌入药企CRM系统（Veeva/NGES）给内部业务人员（医药代表、MSL医学专员）使用的决策推荐引擎。
### 业务侧看到的产品形态
1. CRM系统内的推荐面板：点开某一位医生档案，系统给出建议：
    
    > 建议本周优先线下拜访张医生；沟通重点：XX临床试验数据；配套推送《XX适应症专家共识》电子版资料；不建议电话打扰（该医生历史电话回复率极低）。
2. 代表拜访前AI预生成沟通简报（Pre‑call简报）：医生处方变化、过往互动记录、参加过什么学术会议、关注点，直接给到代表做拜访准备，就是NBC的输出。
3. 批量策略调度：哪些医生触发线上会议邀约、哪些发送学术邮件、哪些暂时减少触达避免骚扰。
4. 配套效果监控看板：统计推荐策略执行率、医生互动反馈、处方变化，持续迭代模型策略。

### 工程师要做的工程落地（JD里写的工作）
1. **数据工程**：把HCP360、CRM拜访记录、学术互动、处方、线上阅读行为多源数据做清洗、特征工程；
2. **模型接口适配**：算法团队产出预测模型，工程侧封装接口，接入CRM；
3. **策略逻辑开发**：叠加业务合规规则（哪些医生不能拜访、哪些内容不能推送），把模型打分转成可执行的行动建议；
4. **上线部署+监控体系**：策略推到生产环境，开发指标监控，看推荐被代表采纳率、HCP互动效果，做迭代优化。

> 注意：**不会直接AI自动给医生发消息**，医药行业强合规，全部是给到代表做参考，人做最终确认执行，不能系统自动对外输出营销内容。

## 二、和电商智能对话、商品推荐的相同点 & 核心差异
| 维度             | 电商商品推荐/智能对话                                        | 药企NBA/NBC智能营销                                          |
| ---------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **相同底层逻辑** | 都是基于用户历史行为做预测，输出个性化建议，属于推荐引擎大类 | 基于HCP历史行为预测，输出个性化行动建议                      |
| **服务对象**     | 直接面向C端消费者，系统直接给用户展示商品、自动发消息        | **服务内部员工（医药代表），不直接面向医生**；人做最终决策，AI只做参谋 |
| **输出内容**     | 推荐商品、优惠券、自动客服对话                               | **不推销商品（药品）**，输出：拜访优先级、沟通渠道、学术资料、谈话要点，属于B2B专业学术运营 |
| **约束条件**     | 主要是业务规则；合规约束弱                                   | 极强医药合规约束：推送内容必须是审批过的学术材料，禁止违规营销，所有操作留审计日志 |
| **数据来源**     | 浏览、点击、加购、购买                                       | 医生处方行为、拜访记录、学术会议参与、线上资料阅读、CRM交互记录；没有“购买”这个动作 |
| 交互形态         | 用户主动触发，实时会话                                       | 以离线批量策略为主，也有单医生档案的实时推荐，没有和医生直接AI聊天对话 |

> 简单一句话类比：
> 电商：**系统直接给顾客推买什么东西**；
> 药企NBA：**系统给销售代表推“你接下来应该对这个医生做什么学术沟通”**，代表拿着建议再去和医生打交道。
