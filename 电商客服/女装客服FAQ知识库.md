## 一、尺码与版型

### Q1 尺码标准吗？该怎么选码？
- 相似问法：尺码准吗 / 按平时码买可以吗 / 尺码会不会偏
- 标准答案：亲，本店商品标注尺码均为标准版型，可以按您平时穿的尺码购买哦。如果想更精准，建议您找一件日常穿着合身的衣服平铺测量肩宽、胸围、腰围，对照商品详情页的尺码表选择最合适的数据~

### Q2 我身高xx、体重xx，穿什么码？
- 相似问法：推荐尺码 / 170斤穿什么码 / 帮我选码
- 标准答案：亲，把您的身高体重告诉我，客服帮您参考推荐哦~ 温馨提示：推荐仅供参考，每个人身材比例和穿着习惯不同，最稳妥的方法还是对照详情页尺码表，用平铺测量数据来选码，这样最准确呢。

### Q3 这款会偏大还是偏小？
- 相似问法：版型偏大吗 / 要不要拍大一码 / 跑码吗
- 标准答案：不同款式版型不同哦：宽松廓形、oversized款视觉上偏大是设计效果；修身款建议按实际测量数据选码。详情页有版型说明和模特身高体重参考（模特身高、体重、所穿码数），可以对照参考一下~

## 二、面料与材质

### Q4 这件是什么面料/成分？
- 相似问法：面料是什么 / 含棉吗 / 什么材质
- 标准答案：亲，商品详情页材质栏有准确的成分标注（如100%纯棉、聚酯纤维等），和实物吊牌一致哦。如果您对材质有特殊要求（比如皮肤敏感），可以先查看成分标或咨询客服，我们如实告知~

### Q5 面料会起球、褪色吗？怎么洗护？
- 相似问法：会缩水吗 / 怎么洗 / 掉色吗
- 标准答案：按洗涤标签护理可以大大降低起球、褪色风险哦：建议冷水洗涤、深浅色分开洗、深色衣物反面晾晒、避免暴晒和长时间浸泡。特殊面料（如真丝、羊毛）建议干洗或参照吊牌洗涤说明~

## 三、颜色与色差

### Q6 实物和图片颜色一样吗？
- 相似问法：有色差吗 / 实物什么颜色 / 和图片一致吗
- 标准答案：亲，本店商品均为100%实物拍摄，但因不同显示器显示效果和拍摄光线原因，可能存在轻微色差，属于正常现象，不影响穿着哦。如果您对颜色特别在意，可以联系客服要细节实拍图，帮您确认~

## 四、发货与物流

### Q7 什么时候发货？
- 相似问法：几天发货 / 何时发货 / 多久能发
- 标准答案：现货商品48小时内发货哦，一般当天16点前下单当天或次日发出（大促期间可能有延迟，请谅解）。预售商品以详情页标注的发货时间为准，介意等待的话建议选择现货或分开下单~

### Q8 发什么快递？可以指定吗？
- 相似问法：发什么快递 / 能发顺丰吗 / 换快递
- 标准答案：亲，默认合作快递是中通/圆通（偏远地区以实际可达为准）。如需指定顺丰等其他快递，可以联系客服补运费差价安排哦~

### Q9 怎么查物流？
- 相似问法：物流到哪了 / 快递单号 / 包裹在哪
- 标准答案：发货后您可以在订单页点击「查看物流」实时跟踪包裹动态，也可以把订单号发给客服帮您查询哦。包裹显示派送后请保持电话畅通，签收时建议当场检查，有问题第一时间联系我们~

## 五、退换货

### Q10 支持七天无理由退货吗？
- 相似问法：可以退吗 / 7天无理由 / 不想要了能退吗
- 标准答案：支持的亲~自签收商品次日起7天内，可以申请七天无理由退货。需要商品保持完好：未洗涤、未穿着（试穿不影响）、吊牌完整、赠品配件齐全、不影响二次销售。退货时商品本身、配件及赠品需一并退回哦。您可以在订单页面提交退货申请，审核通过后会推送退货地址。

### Q11 退货运费谁来承担？
- 相似问法：运费谁出 / 退货要运费吗 / 运费险怎么用
- 标准答案：分两种情况哦：①质量问题、发错货、漏发等商家责任的，往返运费由本店承担，您寄回时可先垫付并保留运费凭证，我们处理完售后为您报销；②个人原因（尺码不合适、不喜欢等）的无理由退换，运费需要您自行承担，若订单含运费险，退货完成后按保单规则自动理赔~

### Q12 收到衣服有质量问题怎么办？
- 相似问法：衣服有瑕疵 / 开线了 / 破洞 / 起球严重 / 和描述不符
- 标准答案：非常抱歉给您带来不好的体验，亲~麻烦您先拍下问题部位的清晰照片或短视频（如破洞、开线、色差、污渍、尺寸不符等），我们核实后按平台规则处理：确认属于质量问题或描述不符的，支持退货退款、换货或补发，运费由本店承担，全程跟进处理进度~

### Q13 什么情况不能退？
- 相似问法：为什么拒绝退货 / 穿过了能退吗 / 剪了吊牌能退吗
- 标准答案：亲，根据七日无理由退货规定，服装类商品商标标识被摘、标识被剪，或商品受污、受损，影响二次销售的，不在无理由退货范围内哦。正常试穿（不影响二次销售）是可以退的呢~

### Q14 可以换货吗？怎么换码/换色？
- 相似问法：换码 / 换颜色 / 能换货吗
- 标准答案：可以换的亲~在库存允许范围内支持换码数或颜色。建议您在订单页直接申请「换货」并备注要换的规格，或者联系客服帮您查目标尺码库存、优先安排交换，比退货重拍更省事哦~

## 六、退款

### Q15 退款多久到账？
- 相似问法：退款什么时候到 / 钱退到哪 / 退款时效
- 标准答案：亲，退货商品签收核验无误后，我们会在7日内按原支付路径退款；到账时效以支付平台为准，支付宝/微信一般1-3个工作日内到账哦~

### Q16 退款进度怎么查？
- 相似问法：退款到哪一步了 / 退的钱呢
- 标准答案：您可以在订单页「退款详情」查看实时进度（申请中→商家审核→买家退货→商家收货核验→退款中→退款成功）。有疑问随时留言，客服第一时间帮您跟进~

### Q18 有优惠券/活动吗？
- 相似问法：有没有券 / 满减 / 新客优惠
- 标准答案：有的亲~店铺首页领券中心可以领券，新客礼金、满减活动详见店铺活动页；收藏店铺还能第一时间收到上新和促销提醒哦~

## 八、库存与预售

### Q19 有货吗？什么时候补货？
- 相似问法：断货了吗 / 还能买吗 / 补货
- 标准答案：页面显示即为实际库存，可以放心下单哦~如果显示缺货，可以联系客服登记补货通知，到货第一时间提醒您~

### Q20 预售是什么意思？要等多久？
- 相似问法：预售多久发货 / 现货预售区别
- 标准答案：预售商品按详情页标注的时间安排发货（一般7-15天，最长不超过平台规定的预售时限）；下单后发货前可以申请退款。介意等待的话建议选择现货商品，预售和现货建议分开下单，避免影响现货发货速度哦~

## 【兜底范围说明】（知识库未覆盖时使用）

以下类型问题不在 FAQ 覆盖范围内，触发兜底策略：
